# Lean Hypertext 2 theme and demo suite

- Date: 2026-10-12 PDT
- Session: 84621ccf-754d-425f-b4b3-ce03fbfe6374
- Outcome: Completed and published for review
- References: PR #117; commits `869cacd` through `f8c0db2`

## Summary

Rebuilt Hypertext as a lean Grav 2 theme focused on semantic HTML5, minimal
runtime work, small packages, and optional aesthetics. The implementation
removed response-wide HTML/image post-processing, flattened configuration to
global defaults plus explicit page overrides, centralized repeated rendering,
kept five collection layouts, and narrowed explicit plugin support. Five
focused demo packages now exercise journal, catalog, resume, documentation,
and restaurant use cases across 69 content pages, nested collections, broad
Markdown/HTML, realistic navigation, overlapping taxonomies, and responsive
media. Later fixes corrected site-wide style scope, taxonomy separators,
undersized image derivatives, and the cards layout. Live demo Admin save
failures were traced to copied-file ownership and repaired across all five
focused previews.

## Decisions

The core theme remains unstyled by default and ships separately from extended
styles and demo content. Parent configuration inheritance was intentionally
removed; site-wide settings belong in theme configuration, while collection
behavior belongs in collection frontmatter. Cards use a responsive two-column
grid with 16:9 previews; article pages use a shallower header strip.
