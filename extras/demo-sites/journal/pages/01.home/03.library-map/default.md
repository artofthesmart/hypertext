I started making a branch map after missing two returns in the same month. The project grew into a small guide to
the city: where the quiet room sits, which branch keeps the best zines, and which lobby has the most dependable outlets.

===

## Branch notes

| Branch | Best time | Notes |
|---|---|---|
| Central | 9:00–10:30 | Bright tables, fast checkout, loud pigeons outside |
| West End | 1:00–3:00 | Deep chairs, generous reference desk, very good map wall |
| River Annex | After work | Small but calm, with a useful copier and a narrow garden |

The map itself is easier to read when I keep the legend short. I use two colors, one symbol for study space,
and a tiny star for branches where the staff remember your name.

<blockquote>
<p>Good libraries are not just shelves; they are instructions for how to spend an hour without rushing.</p>
</blockquote>
