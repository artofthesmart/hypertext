This page connects the names in the glossary to the commands in the reference section.
It helps new readers see how the vocabulary maps to the actual workflow.

===

| Term | Command | Meaning |
|---|---|---|
| preview | `lantern serve` | Inspect the site before publication |
| build | `lantern build` | Render content to static HTML |
| validate | `lantern validate` | Check structure and frontmatter |

<p><kbd>Tab</kbd> and <kbd>Shift</kbd> + <kbd>Tab</kbd> remain the simplest way to move between the docs and the command line without losing context.</p>
