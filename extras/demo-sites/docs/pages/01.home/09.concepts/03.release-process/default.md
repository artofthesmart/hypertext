The release process begins with validation and ends with a package that can be copied without further editing.
That makes it possible to trust the output even when the input tree is still growing.

===

1. Validate the content tree.
2. Build the site.
3. Inspect the generated output.
4. Publish only after the checks pass.

A short pipeline is easier to keep honest than a long one.
