Download the archive for your platform, place `lantern` on your path, and run `lantern version`.

===

## Quick steps

1. Check that your shell can find the binary.
2. Confirm the executable bit is preserved.
3. Create a fresh output directory before the first build.

<blockquote>
<p>Installation is successful when the tool is boring.</p>
</blockquote>

Lantern has no runtime dependencies. The optional preview server requires an available local port and nothing else.
